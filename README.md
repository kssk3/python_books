# 도서 관리 시스템

- 객체지향(OOP) 확장 가능한 도서 모델 설계
- 코드를 패키지 및 모듈 구조로 분리해 재사용
- try-except 디버깅으로 실행 오류를 진단하고 수정하기

## 구현 목록

- [x]도서 속성(도서명, 저자, ISBN)을 지닌 상위 클래스를 정의하기
- [x]하위 클래스(일반 단행본, 전자 도서)를 구성
- [x]개별 도서 상세 정보(딕셔너리), 고유 식별 번호 목록(집합)을 활용하여 도서 관리
- [x]특정 도서 ISBN 입력받아 대여 가능 여부 확인
- [x]중복 ISBN 입력이나 공백 등 유효하지 않은 입력은 차단
- [x]메뉴 선택과정 숫자 입력시 문자 입력으로 발생할 오류 타입 처리
- [x]입력 단계에서 올바른 값만 받도록 유효성 검증 로직 구현
- [x]존재하지 않는 도서 반납시 예외 처리

### 심화 구현

- 도서 대여, 반납시 발생하는 데이터를 튜플 구조로 묶고 리스트로 관리(순차적)
- 저장된 이력 데이터를 바탕으로 월간 대여 통계 또는 가장 많이 대여된 도서 목록
  콘솔 화면에 출력
- 오류가 발생하지 않도록 처리 과정 로그로 기록
